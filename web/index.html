The centre's own day count

A Form F that was never written is invisible to a register that does not hold it. Enter the day's count from the OPD register, the appointment book or the machine log, and the month is reconciled against it. Record a quiet day as nil: a silent month and a nil month look the same from outside, and only one of them is a record.

What this register does not store

A tool that silently dropped part of a statutory form would be worse than one that never offered the form. Each omission is listed here, printed at the foot of every page, and nowhere hidden.

Where the data is

Everything is in one file on this computer, written by this program and read by nothing else. There is no account, no server and no upload. This program makes no outbound network connections of any kind, so patient data cannot leave the clinic through it — and it must not leave the clinic by any other route either. Back the file up the way you back up the rest of the clinic's records, and keep it on a machine only the centre's own people can reach.

This tool files nothing. It submits nothing and connects to nothing. The monthly report has to be lodged with your Appropriate Authority in the manner that office requires, and that office's requirements govern over anything stated here. It is a record-keeping aid, not advice.
